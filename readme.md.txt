AI-Powered Sales Performance Analysis

Project Overview

An end-to-end Sales Data Analytics project using Python, MySQL, Power BI and Groq AI. The project analyzes 25,000 sales records to identify business trends, product performance, customer behavior and regional profitability.

Technologies Used

- Python (Pandas)
- MySQL
- Power BI
- DAX
- Groq API (AI-powered analysis)

Project Structure

- "Python/" – Data cleaning, analysis and AI Sales Analyst
- "SQL/" – SQL queries for data analysis
- "PowerBI/" – Interactive Power BI dashboard
- "Screenshots/" – Dashboard screenshots

Key Business Insights

- Total Sales: 1,071,737,175.03
- Total Profit: 116,393,796.55
- Total Quantity Sold: 69,641
- Overall Profit Margin: 10.86%
- Highest Profit Region: West
- Highest Profit Category: Electronics
- Highest Profit Customer: Customer 1826

Key Features

- Data cleaning and preprocessing using Python.
- SQL-based data analysis.
- Interactive Power BI dashboard.
- Sales and profit analysis by product, region and customer segment.
- AI-powered answers to business questions using Groq.
